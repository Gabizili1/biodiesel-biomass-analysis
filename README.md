# Comparative Study of Biodiesels Produced from Waste of Beef Tallow, Avocado Pear, Watermelon and Desert Date

## 📄 Publication Reference
This baseline experimental research is published in the *International Journal of Modern Science and Technology (IJMST)*.
* **Citation:** Agbaye, G., Ogo, O., & Bawa, I. (2019). Comparative Study of Biodiesels Produced from Waste of Beef Tallow, Avocado Pear, Watermelon and Desert Date as Alternative Source of Energy. *IJMST*, 4(6), 138–147.
* 👉 **[Read the Full Published Paper Here](https://ijmstpublications.com/article?id=245)**

## 🔬 Project Architecture Overview
This directory serves as a dual-purpose repository combining analytical data reporting with interactive computation modeling tools for alternative biomass conversion techniques:
1. **Empirical Benchmarks:** Complete analytical profiles for Fatty Acid Methyl Esters (FAME) generated via NaOH-catalyzed transesterification from variable organic streams.
2. **Computational Automation Tools:** Python processing pipelines engineered to run mathematical multi-feedstock blending combinations and forecast property metrics against international ASTM standard limitations.

## 📁 Repository Map
* `/data`: Structured database tables containing percentage extraction metrics and individual baseline experimental variables.
* `predictive_modeling.py`: Data ingestion script that evaluates baseline values and automatically renders feature correlation charts.
* `blending_simulator.py`: Interactive simulation toolkit allowing custom mixture optimization mapping for arbitrary volumetric ratios.
* `/documents`: Archive layout hosting peer-reviewed asset publications.

## ⚙️ How to Execute the Analytics Engines
Verify system packages are installed via your Ubuntu terminal:
```bash
sudo apt update && sudo apt install -y python3-pandas python3-numpy python3-sklearn python3-seaborn python3-matplotlib
```

Run the predictive analyzer script to auto-generate correlation matrices:
```bash
python3 predictive_modeling.py
```

Execute the simulation engine to test custom compound proportions:
```bash
python3 blending_simulator.py
```
